# Security Policy

## Supported version

Security updates are applied to the current `main` branch.

## Reporting

Please use GitHub private vulnerability reporting when available. Do not include
real customer, policy, claim, identity, credential, or insurer-confidential data
in an issue, pull request, sample file, or reproduction.

## Data safety

This repository is designed exclusively for synthetic data. Any accidental real
personal or confidential data should be removed from distribution immediately and
handled under the relevant legal, privacy, and incident-response process.
